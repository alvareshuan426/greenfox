# Сайт GreenFox — как запустить

Файлы сайта: `index.html`, `thanks.html` (страница после оплаты), `consent.html` (согласие на обработку ПД), `privacy.html`, `offer.html`, `styles.css`, `script.js`, `config.js`, папка `img/`.
Все настройки (цены, проданные места, ссылки на оплату и на канал) — в файле `config.js`.

## 1. Как вы будете видеть ники покупателей

Каждый заказ (дата, имя, контакт, **ник в Telegram**, способ оплаты, цена, отметка о согласии)
отправляется в Google-таблицу и — по желанию — сообщением вам в Telegram.

1. Создайте Google-таблицу. В первой строке напишите заголовки:
   `Дата | Имя | Контакт | Telegram | Оплата | Цена | Тариф | Согласие ПД | Оплачено?`
2. Меню **Расширения → Apps Script**, удалите всё и вставьте код ниже.
3. Если хотите уведомления в Telegram — создайте бота через @BotFather, впишите токен
   и свой chat id (узнать можно у @userinfobot). Если не нужно — оставьте пустыми.
4. **Начать развёртывание → Новое развёртывание → Веб-приложение**.
   Выполнять от имени: «Я». Доступ: «Все». Скопируйте ссылку.
5. Вставьте ссылку в `config.js` → `orderWebhook: "…"`.

```js
const BOT_TOKEN = "";   // токен бота от @BotFather (необязательно)
const CHAT_ID   = "";   // ваш chat id (необязательно)

function doPost(e) {
  const o = JSON.parse(e.postData.contents);
  SpreadsheetApp.getActiveSpreadsheet().getSheets()[0].appendRow([
    o.date, o.name, o.contact, o.telegram, o.payment, o.price, o.tariff, o.consent, ""
  ]);
  if (BOT_TOKEN && CHAT_ID) {
    UrlFetchApp.fetch("https://api.telegram.org/bot" + BOT_TOKEN + "/sendMessage", {
      method: "post",
      payload: {
        chat_id: CHAT_ID,
        text: "🌿 Новый заказ\n" + o.name + "\n" + o.contact +
              "\nTelegram: " + o.telegram + "\nОплата: " + o.payment + " · " + o.price + " ₽",
      },
    });
  }
  return ContentService.createTextOutput("ok");
}
```

Токен бота хранится в Apps Script, а не на сайте — посторонние его не увидят.

**Как одобрять заявки:** в настройках канала включите «Заявки на вступление».
Когда приходит заявка — найдите ник в таблице, проверьте, что оплата прошла (в кабинете платёжного сервиса), и одобрите.

## 2. Оплата через Т-Банк: целиком, «Долями» и рассрочка

1. Подключите интернет-эквайринг в Т-Бизнесе и попросите менеджера включить «Долями» и рассрочку
   (уточните у банка, доступно ли это для вашего статуса — ИП или самозанятая).
2. Создайте ссылки на оплату — по одной на каждый способ и каждую цену (1 500 ₽ и 2 900 ₽) — и вставьте их в
   `config.js` → `paymentLinks`. После отправки формы покупатель сам попадёт на нужную ссылку.
3. **Страница успешной оплаты** — в настройках эквайринга/ссылки укажите адрес `https://ваш-сайт/thanks.html`.
   Туда покупатель попадёт сразу после оплаты и увидит кнопку «Подать заявку в канал».

## 3. Закрытый канал с заявками

1. В канале: **Управление каналом → Пригласительные ссылки → Создать ссылку** → включите **«Заявки на вступление»**.
2. Скопируйте ссылку и вставьте в `config.js` → `channelLink`.
3. Чтобы методичку было сложнее разнести по чатам, в настройках канала включите **«Запретить копирование»** —
   тогда посты нельзя переслать и сохранить.

По такой ссылке человек не попадает в канал сразу — он только подаёт заявку. Даже если ссылку перешлют,
вы одобряете только ники из таблицы заказов с подтверждённой оплатой, остальных отклоняете.

## 4. Ранняя цена

Когда продаётся очередное место, увеличьте `seatsSold` в `config.js`.
Как только `seatsSold` станет равен 10 — сайт сам переключится на 2 900 ₽ и уберёт счётчик.

## 5. Перед запуском

- заполните выделенные поля (ФИО, ИНН, e-mail) в `consent.html`, `privacy.html`, `offer.html` и в подвале `index.html`;
- проверьте текст о себе в блоке «Автор»;
- проверьте ссылку на Instagram (`@greenfox.msk`).

## 6. Хостинг

Сайт статический — подойдёт любой хостинг: Netlify, Vercel, GitHub Pages, Timeweb, REG.RU.
Достаточно загрузить папку целиком.
